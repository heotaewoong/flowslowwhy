# Developer Portfolio Website

현대적인 React 기반의 개발자 포트폴리오 웹사이트입니다.

## 🚀 Features

- ✨ 현대적인 UI/UX 디자인
- 📱 완전 반응형 디자인
- 🎨 푸른색 계열의 세련된 테마
- ⚡ 빠른 로딩 속도 (Vite 사용)
- 🎭 부드러운 애니메이션 (Framer Motion)
- 📊 기술 스택 시각화
- 📝 블로그 연동 (Tistory RSS)
- 📧 연락처 폼

## 🛠️ Tech Stack

- **React 18** - UI 라이브러리
- **Vite** - 빌드 도구
- **Tailwind CSS** - 스타일링
- **Framer Motion** - 애니메이션
- **React Icons** - 아이콘

## 📦 Installation

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 빌드 미리보기
npm run preview
```

## 🎨 Customization

### 색상 테마 변경

`tailwind.config.js`에서 색상 팔레트를 수정할 수 있습니다.

### 개인 정보 수정

각 컴포넌트 파일에서 개인 정보를 직접 수정할 수 있습니다:
- `Hero.jsx` - 이름, 소개
- `About.jsx` - 개인 정보
- `Experience.jsx` - 경력 사항
- `Education.jsx` - 교육 이력
- `Skills.jsx` - 기술 스택
